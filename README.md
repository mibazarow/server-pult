# ServerPult

**Настольное приложение (macOS) для управления домашним ИИ-сервером по локальной сети.**

ServerPult — это «пульт» с одним окном, из которого запускаются и переключаются локальные
языковые модели, ведётся чат с моделью, генерируются картинки, музыка и звуки, а также
видно состояние железа. Никаких облаков и API-подписок: всё считается на своём сервере
с NVIDIA-видеокартой, а приложение лишь управляет им по SSH.

---

## Зачем это нужно

Домашний ИИ-сервер (llama.cpp, генераторы картинок и звука) обычно живёт на одних командах:

- поднять/остановить модель — руками по SSH;
- перед генерацией картинки не забыть остановить LLM, чтобы освободить видеокарту;
- после генерации забрать файлы и не забыть вернуть модель обратно;
- отдельно смотреть `nvidia-smi`, температуры и логи.

ServerPult собирает всё это в одно окно: список моделей с переключением в один клик,
кнопки генерации, дашборд с загрузкой GPU и живой лог. Про «остановить LLM → сгенерировать →
вернуть LLM» приложение помнит само.

---

## Возможности

- **Дашборд** — GPU (загрузка, VRAM, ватты, температура), CPU/RAM/диск, аптайм, кто сейчас
  держит видеокарту. Обновляется автоматически.
- **LLM** — список всех моделей сервера, текущая помечена; клик по другой выгружает текущую
  и загружает выбранную. Кнопка «Остановить».
- **Чат** — потоковый диалог с загруженной моделью; системный промпт, `temperature`, `max tokens`.
- **Картинки** — Z-Image с предзаполненными положительным и отрицательным промтами, выбор
  размера, шагов и CFG; опционально апскейл **SUPIR ×2**.
- **Аудио** — музыка и песни через **ACE-Step** и короткие звуки (SFX) через **MOSS-SoundEffect**.
- **Логи** — живой `tail` логов модели, температур и конкретного задания, с поиском и паузой.
- **Очередь заданий** — задания идут по одному на видеокарте; перед генерацией приложение
  освобождает GPU и возвращает модель после.

## Как это устроено

ServerPult — тонкий клиент. Вся тяжёлая работа — на сервере, приложение только вызывает
серверные команды и показывает результат.

```
┌────────────── Mac (ServerPult) ──────────────┐
│  Tauri 2 · React · TypeScript · Tailwind     │
│  секреты — в macOS Keychain                   │
└───────────────┬───────────────────────────────┘
                │ SSH (управление)  +  HTTP :8080 (чат, OpenAI-совместимый)
┌───────────────▼────────── Linux + NVIDIA ─────┐
│  /opt/kilo-tools/control/*  — JSON-обёртки    │
│  llama.cpp (LLM API), генераторы картинок/аудио│
│  jobs/ — задания, очередь на одну GPU         │
└───────────────────────────────────────────────┘
```

- Управление — по **SSH** (пароль хранится в Keychain; ключи не используются).
- Чат — по HTTP к локальному API `llama.cpp` (`/v1/chat/completions`).
- Результаты генерации сохраняются в `~/Downloads/generated`, после чего файл и каталог
  задания удаляются на сервере.
- Только локальная сеть: никаких VPN, проброса портов и внешних сервисов.

## Сборка и запуск

Нужны **Node.js**, **pnpm**, **Rust** и Xcode Command Line Tools.

```bash
pnpm install
pnpm tauri dev      # запуск в режиме разработки
pnpm tauri build    # сборка приложения (.app / .dmg)
```

---

## Первый запуск

1. Открой раздел **«Настройки»**.
2. Укажи адрес сервера, порт (обычно 22), пользователя и пароль.
3. Нажми **«Проверить связь»** — должна вернуться строка с ОС и числом ядер.
4. При необходимости впиши **ключ LLM API** (для чата).
5. **«Сохранить»** — пароль и ключ уходят в macOS Keychain, а не в файл.

> **Доступ к локальной сети.** При первом подключении macOS спросит разрешение на доступ к
> устройствам в локальной сети — нужно **разрешить**. Если окно не появилось или доступ был
> отклонён, включи приложение вручную: **Системные настройки → Конфиденциальность и
> безопасность → Локальная сеть**. Без этого приложение получит ошибку «No route to host».

## Что должно быть на стороне сервера

Приложение вызывает по SSH тонкие обёртки, печатающие JSON в `stdout`:

| Команда | Назначение |
|---|---|
| `control/system.sh` | статус железа (GPU, CPU, RAM, диск, аптайм) |
| `control/llm.sh status\|list\|start <id>\|stop` | управление языковыми моделями |
| `control/image.sh …` | запуск задания генерации картинки → `{ "job_id": … }` |
| `control/audio.sh music\|sfx …` | запуск аудио-задания → `{ "job_id": … }` |
| `control/job.sh status\|list\|cancel\|cleanup` | состояние задания, отмена, очистка |
| `control/log.sh llm\|temps\|job <id>` | текст логов |

Обёртки — тонкий слой поверх уже существующих скриптов сервера; ядро менеджера моделей и
генераторов остаётся на сервере.

---

## Безопасность

- В репозитории **нет** паролей, ключей и адресов — всё вводится пользователем и хранится в
  macOS Keychain.
- Подключение только по локальной сети.
- Пароли, ключи и локальные конфиги исключены через `.gitignore`.
